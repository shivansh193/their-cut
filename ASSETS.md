## Narration and title cards

The narration was synthesised offline with the Windows "Microsoft Zira" SAPI voice by `scripts/build-fixtures.ts`. The script and the brand names in it ("Sunny Oats", "Green Crate", "Brightblend") are invented for the demo. Title cards are generated by ffmpeg in the Segoe UI font, rendered locally; no font file is redistributed.

## Ground truth

`fixtures/videos/*/truth.json` is generated from the edit list in `fixtures/videos/spec.json`:

- **Visual presence:** labelled per edit segment, after a 1 fps frame-by-frame review of each source clip. Clips where a child is hidden or out of frame are trimmed so each segment's label is unambiguous. One deliberate hard case: in `sunday-lunch`, Mia is small and partly hidden in the background of clip 5136238.
- **Narration presence:** the exact time span of each narration line, tagged with the children it is about. This includes pronoun-only lines such as "She always says that."
